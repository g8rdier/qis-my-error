## Artifact provenance

- `artifacts/manifest.json` records circuit fingerprints and H/L/p hashes.
  Generated by `build_graphs.py` from the supplied train **circuits**, not labels.
- `../lut/manifest.json` identifies the original 10M-shot/basis table build,
  Stim seeds 20261113/20261114. Generated by `../build_lut.py`.
- `../pair_index.py` constructs all physical two-error effects at import time
  for the closure model. It uses graph columns only; no sample data or labels.
- `../experiments/results/*` records code/table hashes, full configurations,
  independent seed families, per-basis/bit errors and paired comparisons.

For a new experiment, create a new named JSON rather than overwriting frozen
model files. `config.json` is just the selected copy; the immutable named file
remains the reproducible identity. `BPOSD_CONFIG=<filename>` chooses another
configuration before import; `benchmark.py --config <filename>` handles that.

The improved candidate uses CPU shot parallelism and supports 48 judge threads.
No B200/GPU timing has been measured. Laptop time is not the judging time cap.
